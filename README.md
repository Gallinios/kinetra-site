# Kinetra – Landing page

Concept landing page για ένα φανταστικό brand συνδεδεμένων οργάνων μέτρησης για φυσικοθεραπεία και αθλητισμό (πλατφόρμες δύναμης, δυναμόμετρα, αισθητήρες κίνησης).

> Το «Kinetra» είναι φανταστικό brand. Όλα τα προϊόντα, οι προδιαγραφές και τα στοιχεία της εταιρείας είναι επινοημένα για τις ανάγκες του σχεδιασμού.

## Χαρακτηριστικά

- Responsive σχεδιασμός για κινητό, tablet και υπολογιστή
- Αυτόματο light / dark mode ανάλογα με τις ρυθμίσεις του συστήματος
- Κινούμενο γράφημα δύναμης αριστερού–δεξιού σε `<canvas>`
- Φίλτρο κατηγοριών στην ενότητα «Πόροι»
- Συχνές ερωτήσεις που ανοίγουν με κλικ (`<details>`)
- Φόρμα demo με έλεγχο πεδίων (χωρίς αποστολή δεδομένων)
- Σέβεται τη ρύθμιση `prefers-reduced-motion`
- Chatbot που απαντά σε συχνές ερωτήσεις από τα στοιχεία του site, χωρίς server

## Τεχνολογίες

- HTML, CSS και JavaScript χωρίς frameworks, σε ένα αρχείο
- Γραμματοσειρές από Google Fonts: Commissioner, Noto Sans, JetBrains Mono

## Εκτέλεση

Άνοιξε το `index.html` σε οποιονδήποτε browser. Δεν χρειάζεται εγκατάσταση.
